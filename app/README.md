# App
This application allows user interaction with the database. Made in Python using Visual Studio Code, I set up the connections to correctly connect MySQL with Python using the mysql.connector library. Once run, the user can choose an option whether to view library stats, update library information, or exit. Users can view the library stats from the given results example which queries an age range and retrieves stats that output how many total members there are along with total checkouts and renewals. Users can also update information, using option two, to modify an individual profile. Using a unique patron ID key matching the auto increment primary key of the schema, it allows users to alter the notification preference code by mapping them to their respective single character codes from the dataset and asking them for a new one. A major challenge that I overcame was making it so the app didn't have any security issues with our databases. The app uses parameterized queries so that user inputs are treated as literal string values so that users cannot input malware. I also learned that hardcoded passwords should be replaced with Python's native os module to dynamically look up credentials from environment variables. We also added input validation filters so that inputs are appropriate and not blank.
