# Documentation README
I first started building the database on MySQL Workbench by splitting the data into four different tables called libraries, patron_types, patrons, and patron_activity based on their attributes. I then loaded the CSV file using the Table Data Import Wizard and wrote an optimization script with custom indexes so that the data could run quicker. Next, I added a user interface program built with Python using Visual Studio Code. The interface allows users to run queries on age demographics, retrieve usage metrics, and securely update individual profile notification settings. To be able to replicate this project, you must first run the create_table schema file inside the scripts folder to build the tables, import the dataset using the Table Data Import Wizard, and then run the migration schema file also inside the scripts folder. Once the database is ready, install the database adapter with the terminal command pip install mysql-connector-python, save your database password as an environment variable, and launch the app by opening up your terminal in your main folder and running python app/main.py. The user interface application was made with security in mind. I utilized parameterized queries to force MySQL to handle all user inputs as literal string values while implementing the appropriate input validations to avoid unwanted entries.
